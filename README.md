# 白宝的QQ好友名单增减对比器

一个纯本地运行的 Windows 小工具，用于比对两次 QQ 好友名单，找出“谁把你删了”或者“新加了谁”。

## 背景故事
新版 QQ 砍掉了“导出好友列表”功能，导致我们无法直观地发现好友数量变化时少了谁。本工具通过 **网页抓取 -> 本地清洗 -> 本地对比** 的方式，帮你解决这个痛点。

## 功能特色
- **纯本地运行**：不登录 QQ、不联网、不收集任何隐私数据。
- **精准识别**：只认带有专属前缀的 QQ 号，不受好友改名、纯数字昵称、空白昵称的干扰。
- **去重清洗**：附带清理工具，自动去重并格式化。
- **双窗口对比**：如果同时有新增和减少，会分两个窗口清晰展示。

## 如何使用
1. 下载 Release 中的压缩包并解压。
2. 双击 `介绍与教程.txt`，按照里面的保姆级步骤操作即可。
